# yt-agent: Viral YouTube Shorts — Diagnosis & Implementation Plan

## Background

After a full audit of the codebase, the pipeline is architecturally sound but the **visual output is the weakest link**. It produces what looks like a static whiteboard diagram presentation — not a viral short. The goal is to fix every layer so a simple prompt produces a cinematic, high-energy 30-second Short that gets auto-uploaded.

---

## 🔥 Root Cause Diagnosis

### Weak Area 1 — Backgrounds Are Flat Gradients (CRITICAL)
**File:** `SceneRenderer.tsx` lines 40–48  
The current "backgrounds" are just 6 static CSS linear-gradients (`midnight-blue`, `deep-purple`, etc.). They are essentially solid dark rectangles. There is **zero visual motion, no particles, no environment, no texture beyond a 3% noise overlay.**

> This is why the video "feels like a PowerPoint animation."

**Fix:** Replace static gradients with AI-generated cinematic backgrounds (Pollinations image API is already partially wired in) OR animated particle/grid canvas effects directly in Remotion.

---

### Weak Area 2 — Diagram Components Are Barely Animated (CRITICAL)
**File:** `RequestFlowDiagram.tsx` — the dominant visual for nearly every scene.  
The diagrams show boxes connected by dashed lines. Packets animate across edges — but:
- All 7 diagram templates other than `RequestFlowDiagram` (`ArchitectureLayersDiagram`, `ComparisonDiagram`, etc.) are **stub files** (under 2KB each, unimplemented).
- The only real animations are: node spring-in, packet travel, highlight glow.
- There are no **camera zooms, scene-wide pulse animations, or "energy" effects** that viral tech content uses.

**Fix:** Build out all 7 diagram templates properly, add particle burst effects on events, add camera-zoom on scene transitions.

---

### Weak Area 3 — On-Screen Text is Small and Boring (HIGH)
**File:** `SceneRenderer.tsx` `OnScreenText` component (lines 156–218).  
The text appears at the top in a small frosted-glass box, 68px, white. On mobile (which is where Shorts are watched) this is barely readable and has zero impact.

Viral Shorts use **giant bold kinetic text** that fills the frame, sometimes with word-by-word pop animation, neon glows, and color emphasis on key words.

**Fix:** Replace `OnScreenText` with `KineticTextOverlay` — word-by-word timing, scale-pop on entry, big font (120-180px), position varies by scene role (hook = center, explanation = lower third).

---

### Weak Area 4 — Captions Are Static and Generic (HIGH)
**File:** `CaptionsOverlay.tsx`  
Current captions are word-groups in a small semi-transparent box at the bottom. No word highlighting, no pop animation, no color variation. Viral Shorts use **TikTok-style word-at-a-time pop captions** with colored emphasis words.

**Fix:** Implement `PopCaptionsOverlay` — one word at a time, each word pops in with a scale spring, emphasis words get a highlight color.

---

### Weak Area 5 — Transitions Are Weak (MEDIUM)
**File:** `SceneRenderer.tsx` lines 276-280 — only `fade` and `slide` are implemented.  
The prompt supports `cut | fade | slide | zoom | glitch` but `zoom` and `glitch` are missing. Viral Shorts heavily use glitch cuts and zoom punches between scenes.

**Fix:** Implement `zoom-punch` and `glitch-cut` transitions in Remotion.

---

### Weak Area 6 — No AI-Generated Backgrounds Wired Up (MEDIUM)
**File:** `asset_resolver.py` — `StillImageResolver` only activates for `kind="image"` scenes.  
Diagram scenes (which are 100% of output) never get a generated background. The AI background generation capability (Pollinations) is present but gated to a separate scene type.

**Fix:** Add an optional **background layer** to every diagram scene — a Pollinations-generated AI image that gets blurred/blended behind the diagram. This is zero-cost (Pollinations free tier).

---

### Weak Area 7 — No Music/SFX Layer (MEDIUM)
There is narration audio but **no background music or sound effects**. Music is one of the biggest drivers of emotional engagement and watch-through rate on Shorts.

**Fix:** Add a free royalty-free music track layer in Remotion with automatic ducking under narration. Use a static library of ~5 tracks (free from YouTube Audio Library).

---

### Weak Area 8 — LLM Prompt Doesn't Drive Viral Hooks (MEDIUM)
**File:** `prompts/script_video_prompt.md`  
The hook examples in the prompt are weak: *"Your API can fail for this reason"*. Viral tech Shorts use very specific psychological hooks: number-based claims, controversial takes, "X secret that senior devs know", etc.

**Fix:** Update the prompt to enforce viral hook patterns and add a `hook_style` field (numbered, controversial, curiosity-gap, fear-based).

---

### Weak Area 9 — Captions Timing is Approximated (LOW)
**File:** `tts_generator.py` / `captions.py`  
Current captions are generated by splitting narration words and approximating timestamps. This produces caption drift where the word on screen doesn't match what's being said.

**Fix:** Use a word-aligned TTS response or run Whisper locally on the generated MP3 to get accurate per-word timestamps.

## Open Questions

> [!IMPORTANT]
> **Q1 — Background generation API:** You mentioned connecting an external API for backgrounds and icons. Which API do you want to use?
> - **Option A: Pollinations (already wired, free)** — generates AI backgrounds at no cost, ~3-5s per image. Good quality for cinematic backgrounds.
> - **Option B: A paid API** (Stability AI, Midjourney, etc.) — higher quality but has cost.
> - **Recommendation: Pollinations for backgrounds (free), enhance diagrams with better Remotion animations.**

> [!IMPORTANT]
> **Q2 — Music:** Do you want background music added?
> - Option A: Static library of 5 royalty-free tracks bundled in the repo.
> - Option B: AI-generated music via Suno/Udio API (has cost).
> - Recommendation: Start with Option A (zero cost, immediate).

> [!IMPORTANT]
> **Q3 — Caption style:** TikTok-style one-word-at-a-time pop captions, or current group captions?
> - One-word pop captions are much more viral but require accurate word timestamps.
> - This means either using Whisper locally (free, ~15s per run) or a paid TTS with word timestamps.

## Proposed Changes

### Phase 1 — Visual Upgrade (Biggest Impact, 0 Cost)

#### [MODIFY] `SceneRenderer.tsx`
- Replace flat gradient backgrounds with animated **particle grid background** (SVG/canvas, pure Remotion, zero API cost)
- Add `zoom-punch` and `glitch-cut` transitions
- Replace `OnScreenText` with `KineticTextOverlay` (large, word-by-word, neon glow)

#### [NEW] `video-renderer/src/components/ParticleBackground.tsx`
- Animated grid/particle effect that reacts to scene events
- Different color palettes per scene role (hook=red/orange, explanation=blue, insight=green)

#### [NEW] `video-renderer/src/components/KineticTextOverlay.tsx`
- Large (140-180px) bold text
- Scale-pop animation on entry
- Color-coded by scene role

#### [MODIFY] `CaptionsOverlay.tsx`
- Implement TikTok-style word-at-a-time pop captions with spring animation

#### [MODIFY] Remaining diagram stubs
- Properly implement `ComparisonDiagram`, `ArchitectureLayersDiagram`, `ConceptCardDiagram` etc.

---

### Phase 2 — AI Background Layer (Optional, Free with Pollinations)

#### [MODIFY] `asset_resolver.py`
- Add `BackgroundImageResolver` that generates a blurred cinematic background image for ALL scenes (including diagrams), using the scene's `visual.query`
- This gets layered behind the diagram at low opacity/blur

#### [MODIFY] `run_pipeline.py`
- Pass the background image path into `diagram` scene props
- Remotion composites: background image → diagram overlay → text

#### [MODIFY] `SceneRenderer.tsx`
- Accept optional `backgroundSrc` prop, render behind diagram with blur + dark overlay

---

### Phase 3 — Hook Quality Upgrade

#### [MODIFY] `prompts/script_video_prompt.md`
- Add `hook_style` enum: `numbered | controversial | curiosity_gap | fear | promise`
- Add 15 viral hook example templates
- Tighten hook rules: first sentence must be < 10 words, must have a number or a strong verb

#### [MODIFY] `prompts/title_video_prompt.md`
- Add viral title patterns (numbers, brackets, emotional words)

---

### Phase 4 — Music Layer (Zero Cost)

#### [NEW] `data/library/music/` — 5 royalty-free tracks from YouTube Audio Library
#### [MODIFY] `ShortVideo.tsx` — Add `<Audio>` component for background music with volume 0.15

---

### Phase 5 — Accurate Caption Timing

#### [MODIFY] `src/media/tts_generator.py`
- After generating MP3, run `whisper` (via `openai-whisper` Python package) locally to get per-word timestamps
- Use these for caption generation instead of approximated splits

#### [MODIFY] `src/media/captions.py`
- Update to consume Whisper word-level output
